# التحقق من أداء التنقل — 22 سبتمبر 2026

## نطاق التحقق

الاختبار على النسخة المحلية `http://127.0.0.1:8080` باستخدام Chrome المثبت على Windows، عبر Playwright 1.63.0 في جلسة مستقلة. أدوات التحكم المباشر بنافذة المستخدم لم تتصل؛ هذه ليست قياسات من نافذته أو من الإنتاج.

تم الضغط على روابط الشريط العلوي لعشر صفحات بالترتيب ثم بالعكس: الرئيسية، المختبرات، التقنية، النادي، بلس، المقر الرئيسي، المشاريع، المقالات، من نحن، تواصل معنا. كل جولة تشمل 20 انتقالًا، مع تمرير لأسفل ولأعلى في كل صفحة. تبدأ القياسات بعد فتح الصفحة الأولى؛ لا تمثل تشغيل المتصفح أو السيرفر من الصفر.

## الإصلاحات

- نفس جسيمات الكرة وألوانها وحركة التفكك، مع نقل WebGL إلى Worker باستخدام OffscreenCanvas عند توفر الدعم.
- إيقاف الرسم عندما يختفي المستند، وإنهاء العامل عند مغادرة الصفحة، وإعادة تهيئته عند الرجوع. يوجد مسار بديل عند غياب دعم Worker أو فشل تحميله.
- حساب ارتفاع الصفحة عند تغير أبعادها بدل قراءته مع كل حدث تمرير، ودمج تحديثات التمرير في إطار واحد.
- تطبيق الثيم قبل رسم المحتوى، وتجنب استبدال النصوص والاتجاه عندما تكون القيم الحالية صحيحة.
- إزالة mix-blend-mode الزائد من الكرة. مقارنة PNG للكرة الساكنة أعلى الرئيسية قبل الإزالة وبعدها أعطت صورًا متطابقة في الوضعين الفاتح والداكن.

## النتائج

اختبار الضغط بإبطاء المعالج أربع مرات، قبل الإصلاح وبعد نقل الرسم إلى العامل:

| المقياس عبر 20 انتقالًا | قبل | بعد نقل الرسم |
|---|---:|---:|
| وسيط المئين 95 لفواصل الإطارات | 33 ms | 17 ms |
| فواصل إطارات تجاوزت 50 ms | 11 | 4 |
| أطول فاصل إطار مسجّل | 267 ms | 117 ms |
| مهام طويلة على خيط الواجهة | 9 | 5 |
| أخطاء JavaScript | 0 | 0 |

الجولة النهائية بعد إزالة الدمج الزائد، دون إبطاء اصطناعي:

- `DOMContentLoaded`: بين 43 و127 ms. هذا زمن جاهزية DOM منذ بدء التنقل؛ لا يشمل زمن إجراءات أداة الاختبار.
- وسيط المئين 95 لفواصل الإطارات: 17 ms.
- ثلاث فواصل إطارات تجاوزت 50 ms؛ الأطول 83 ms. لا تعني النتيجة انعدام التقطيع تمامًا.
- لم تسجل مهام طويلة أو أخطاء JavaScript في الجولة النهائية.

قياس فواصل الإطارات يستخدم `requestAnimationFrame` ويستبعد أول خمس عينات لكل صفحة. تسجيل المهام الطويلة يبدأ مبكرًا عند إنشاء المستند. الفواصل مؤشر على سلاسة الواجهة، وليست قياسًا مستقلًا لكل إطار يظهر على الشاشة. النتائج عينة محلية وتتأثر بالحمل على الجهاز؛ لوحظ أثناء العمل انخفاض الذاكرة الحرة إلى أقل من 1 GB وإعادة تشغيل Docker، ولم تُوقف تطبيقات المستخدم الأخرى.

الأدلة الخام: [قبل التعديل](results/baseline.json)، [بعد نقل الرسم](results/after.json)، [الجولة النهائية](results/final.json).

## تحقق الواجهة

نجحت اختبارات العربية وRTL، الثيمين، قائمة الموبايل بعرض 390px، الرجوع بالمتصفح، ظهور الشبكة عند نهاية الصفحة، تفضيل تقليل الحركة، والمسار البديل مع تعطيل Worker في جلسة الاختبار. الرجوع عمل كتصفح عادي؛ لم يدخل Chrome إلى BFCache في هذه الجولة، لذلك لا تُعد تحققًا فعليًا من التخزين الخلفي للصفحة.

تم فحص الصور: [الداكن](results/worker-ar-dark.png)، [الفاتح](results/worker-ar-light.png)، [الموبايل](results/worker-mobile.png)، [الشبكة](results/network.png).

## ظهور الكرة عند إعادة التحميل

تُحمّل معاينة SVG مبكرًا بأولوية عالية، وتُخفى بعد رسم أول إطار للكرة المتحركة. اختُبر فتح الصفحة وإعادة تحميلها مع تأخير ملف الكرة عمدًا؛ ظهرت المعاينة قبل تشغيل WebGL واختفت بعد جاهزيته، دون طلب صورة مكرر. حجم النقل المحلي المضغوط المسجّل للمعاينة نحو 25 KB. لم يتغير أنيميشن صور الأقسام.

لإعادة توليد المعاينة: `python scripts/generate-sphere-preview.py`.

## تكبير الكرة وانتشار الجسيمات — 22 سبتمبر 2026

زاد حجم الكرة ومعاينتها بنحو 13%. تتحول جسيماتها نفسها تدريجيًا إلى حقل منتشر بين 68% و92% من التمرير، وتظل تدور في الخلفية بعد نهاية التحول. يعكس الرجوع بالتمرير التحول لتتجمع الكرة مجددًا. بقي عدد الجسيمات كما هو، مع رسم واحد لكل إطار داخل Worker، وإيقاف الحركة عند إخفاء الصفحة أو تفعيل تقليل الحركة. صُحّح دمج الشفافية للحفاظ على اللون الأزرق في الوضع الفاتح.

اختُبرت النسخة المحلية في Chrome Headless بعرضي 1440 و390 بكسل، مع تمرير متصل للصفحة ذهابًا وإيابًا لمدة أربع ثوانٍ لكل مقاس. بلغ المئين 95 لفواصل إطارات الواجهة نحو 16.9 ms، دون فواصل تتجاوز 50 ms أو مهام طويلة في هذه العينة. هذه محاكاة لمقاس الموبايل على الكمبيوتر، وليست قياسًا على هاتف فعلي أو قياسًا مستقلًا لإطارات GPU.

نجح استمرار حركة الجسيمات في النهاية، وسكونها مع تقليل الحركة، والمسار البديل دون Worker، ولم تُسجل أخطاء JavaScript. الأدلة: [القياسات](results/burst-results.json)، [الحجم الجديد](results/burst-top.png)، [النهاية الداكنة](results/burst-bottom.png)، [النهاية الفاتحة](results/burst-light.png)، [مقاس الموبايل](results/burst-mobile.png).

زادت مسافات تبويبات الناف بار إلى 24–32 بكسل، مع قائمة مدمجة تحت عرض 1280 بكسل. نجح فحص العربية والإنجليزية عند عروض 360 و390 و768 و1024 و1280 و1440 و1920 بكسل، دون تداخل أو تمرير أفقي، مع تحقق التنقل من القائمة المدمجة.

## وضوح الكرة في الوضع الفاتح

زادت عتامة طبقة الكرة في الوضع الفاتح من 0.44 إلى 0.96، وأضيفت درجات أزرق أغمق للرسم في هذا الوضع. تُحدّث ألوان GPU عند تبديل الثيم، بما يشمل الرسم عبر Worker والمسار البديل وتقليل الحركة. بقي عدد النقاط وحركتها كما هما، وعُوّضت عتامة شبكة الخلفية لتظل خفيفة. راجعت المقارنة بصريًا في Chrome Headless عند بداية الصفحة ووسطها ونهايتها، بعرضي 1440 و390 بكسل، دون أخطاء JavaScript. صور المقارنة: [قبل](results/light-visibility-before.png)، [بعد](results/light-visibility-after.png)، [أثناء التمرير](results/light-visibility-middle.png).

## إعادة التشغيل

من جذر المشروع، مع تشغيل الموقع المحلي ووجود Chrome في مساره المعتاد:

```powershell
npm install --prefix .perf-tools playwright-core@1.63.0 --no-audit --no-fund --offline=false
$env:CPU = '4'
$env:LABEL = 'stress'
node scripts/performance/audit.cjs
Remove-Item Env:CPU
$env:LABEL = 'normal'
node scripts/performance/audit.cjs
node scripts/performance/lifecycle.cjs
node scripts/performance/preview-check.cjs
node scripts/performance/sphere-burst-check.cjs
```

تُكتب نتائج التشغيل الجديد داخل `.perf-tools` ولا تستبدل الأدلة المحفوظة في هذا المجلد. تشغيل `lifecycle.cjs` لا يرسل أي نموذج ولا يغير بيانات CMS.
