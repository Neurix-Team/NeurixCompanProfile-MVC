# Local web fonts

These WOFF2 files preserve the public site's existing Google Fonts families and weights:

- Inter: 300–900
- Space Grotesk: 400–700
- IBM Plex Sans Arabic: 300–700

Declarations and language subsets are in `../css/fonts.css`, with `font-display: swap`.
The original OFL licenses are included alongside the fonts. Keep the CSS and font
files together when updating them. Page rendering must not depend on a remote
font stylesheet or CDN.
